# 모해 계산기 (MOHAE Calculator)

MOHAE 메뉴판 계산기 안드로이드 앱. 코드를 올리면 GitHub Actions가 자동으로 APK를 빌드해
[Releases → latest](../../releases/tag/latest) 에 `MOHAE-calculator.apk` 로 올립니다.

메뉴 화면은 `app/src/main/assets/index.html` 입니다.

## 모해 위생기록 (hygiene/)

냉장·냉동 온도, 청소·소독, 입고 검수, 튀김기름 기록 앱. 월별 HACCP 기록표를 PDF로 저장하고,
백업 파일을 Google Drive 등에 저장/복원할 수 있습니다. APK: `MOHAE-hygiene.apk` (같은 Release).
